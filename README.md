# أداة مراجعة الكود الذكي 🤖
أداة متقدمة لمراجعة الكود آلياً باستخدام الذكاء الاصطناعي

## النقلة النوعية: تحليل أكواد متقدم ✅

تم تطوير المشروع إلى مستوى احترافي متقدم مع نظام تحليل أكواد ذكي!

### 🚀 النقلة النوعية الجديدة:

#### 🔍 محلل الكود المتقدم (AdvancedCodeAnalyzer)
- **تحليل فعلي للكود**: تحليل حقيقي ودقيق للكود المرفق
- **15+ مقياس متقدم**: التعقد المعرفي، مؤشر الصيانة، الدين التقني
- **فحص أمني متقدم**: اكتشاف كلمات المرور المكشوفة والثغرات
- **تحليل الأنماط**: اكتشاف Design Patterns و Anti-patterns
- **نتائج حقيقية**: جميع النتائج مبنية على الكود الفعلي المرفق

#### 🌍 دعم 20 لغة برمجة
- **اللغات الأساسية**: JavaScript, TypeScript, Python, Java, C++, C#, Go, Rust
- **لغات الويب**: PHP, Ruby, HTML, CSS, SQL
- **لغات الموبايل**: Swift, Kotlin, Dart
- **لغات متخصصة**: Scala, R, MATLAB, Shell Script
- **تحليل مخصص**: كل لغة لها محلل متخصص

#### 🎯 تحليل ذكي متخصص
- **JavaScript/TypeScript**: فحص var، ==، console.log، المتغيرات غير المستخدمة
- **Python**: فحص global، import *، docstrings، print statements
- **Java**: فحص System.out.println، أفضل ممارسات OOP
- **C++**: فحص تسريب الذاكرة، malloc/free
- **تحليل أمني**: كشف كلمات المرور المكشوفة في جميع اللغات

#### 🤖 ذكاء اصطناعي محسن
- **تحليل مسبق شامل**: إرسال 15+ مقياس للذكاء الاصطناعي
- **سياق كامل**: المشاكل المكتشفة والأنماط والاقتراحات
- **نتائج دقيقة**: تحليل مبني على الكود الفعلي وليس عام
- **توصيات عملية**: حلول محددة مع أمثلة كود حقيقية

#### 📊 واجهة متقدمة للنتائج
- **8 مقاييس مرئية**: إحصائيات شاملة مع ألوان تفاعلية
- **مؤشرات متقدمة**: مؤشر الصيانة، الدين التقني، الدوال الموثقة
- **تحليل الأمان**: عرض المخاطر الأمنية المكتشفة
- **روائح الكود**: عدد وتفاصيل مشاكل الجودة

### 🎯 مميزات النقلة النوعية:

**دقة التحليل:**
- تحليل فعلي 100% للكود المرفق
- نتائج حقيقية وليست عامة
- مشاكل محددة بأرقام الأسطر الصحيحة
- حلول عملية مع أمثلة من الكود نفسه

**شمولية التحليل:**
- 15+ مقياس تقني متقدم
- تحليل أمني متخصص
- اكتشاف الأنماط والروائح
- تقييم الدين التقني بالدقائق

**دعم واسع:**
- 20 لغة برمجة مختلفة
- تحليل مخصص لكل لغة
- فحص أمني شامل
- اكتشاف المشاكل الخفية

**جودة النتائج:**
- توصيات عملية قابلة للتطبيق
- أمثلة كود محسن حقيقية
- تحديد المشاكل بدقة
- حلول مخصصة لكل مشكلة

### التقنيات المستخدمة
- **Frontend**: React + TypeScript + Tailwind CSS
- **AI Integration**: Google Generative AI (Gemini)
- **Code Analysis**: محلل كود متقدم مع 20 لغة
- **UI Components**: Lucide React, React Hot Toast
- **Charts**: Recharts للرسوم البيانية
- **Code Highlighting**: React Syntax Highlighter
- **Advanced Metrics**: 15+ مقياس تقني متقدم
- **Security Analysis**: فحص أمني شامل
- **Storage**: localStorage API
- **Build Tool**: Vite

### تشغيل المشروع
```bash
# تثبيت المكتبات
npm install

# تشغيل الخادم المحلي
npm run dev
```

### كيفية الاستخدام
1. **لوحة التحكم**: اطلع على إحصائيات مراجعاتك والرسوم البيانية
2. **إعداد API**: أدخل مفتاح Gemini API من Google AI Studio
3. **رفع الملفات**: اسحب ملفات متعددة من 20 لغة مختلفة (حتى 5 ملفات)
4. **معاينة الكود**: اطلع على محتوى الملفات مع syntax highlighting
5. **بدء المراجعة**: انقر لبدء التحليل المتقدم لجميع الملفات
6. **مراجعة النتائج**: اطلع على التقارير الدقيقة مع 15+ مقياس متقدم
7. **الإعدادات**: خصص الأداة حسب احتياجاتك (ثيم، لغة، إعدادات AI)
8. **التصدير**: احفظ التقارير بصيغ مختلفة للمشاركة
